软件工程结对作业：校园失物招领 Web 系统

## 项目简介

本项目是一个校园失物招领 Web 系统，采用单文件入口（SPA）+ hash 路由实现，包含首页、发布、搜索、详情、我的寻物、我的招领、我的收藏、个人信息等视图。数据全部保存在浏览器本地，不依赖后端服务和构建工具。界面针对不同屏幕分辨率做了优化，移动端与桌面端均可清晰显示。

## 目录结构说明

```text
项目根目录
├─ index.html      # 实际运行入口（单文件 SPA，hash 路由切换视图）
├─ css/
│  └─ style.css    # 全局样式：页面布局、卡片、弹窗、移动端与桌面端适配
├─ js/
│  ├─ data.js      # 数据层：数据模型、localStorage 读写、种子数据、
│  │               # 发布/查询/筛选/搜索/状态更新/收藏等可测试函数
│  └─ app.js       # UI 与路由：视图切换、动态渲染、表单交互、事件绑定
└─ images/
   ├─ campus-card.jpg
   ├─ keys.jpg
   ├─ water-bottle.jpg
   ├─ umbrella.jpg
   ├─ earphones.jpg
   ├─ books.jpg
   ├─ backpack.jpg
   └─ home_show_top.png
```

各目录/文件作用：

- `index.html`：系统唯一入口文件，通过 hash 路由（如 `#home`、`#publish`、`#search`、`#mine`、`#detail/:id`）显示对应视图。
- `css/style.css`：集中管理所有样式，包括手机框架、卡片列表、弹窗、底部导航及桌面端布局。
- `js/data.js`：数据层，负责定义数据模型、读写 `localStorage`、首次生成示例数据，并暴露 `LostFoundStore` 供 UI 调用。
- `js/app.js`：界面逻辑，负责路由解析、各视图的动态渲染、发布/搜索/收藏/状态更新/编辑等交互。
- `images/`：类别默认图与首页顶部背景图等静态资源。

## 使用说明

### 运行环境

- 推荐使用谷歌浏览器（Chrome）等现代浏览器。
- 无需安装服务器、Node.js 或任何插件。
- 请保持 `index.html`、`css/`、`js/`、`images/` 的相对路径不变，否则样式或图片可能无法加载。

### 启动步骤

1. 下载或拷贝整个项目目录。
2. 找到根目录下的 `index.html`。
3. 双击 `index.html`，选择用谷歌浏览器打开即可进入系统。

### 功能操作指引

1. 首页

    - 默认展示“进行中”的寻物和招领信息。
    - 点击顶部搜索框可进入搜索页。
    - 点击任一卡片可查看详情。
    - 若物品已被标记找回，首页不继续展示该物品信息

2. 发布

    - 点击底部导航“发布”，选择“我要寻物”或“我要招领”。
    - 填写物品类型、名称、地点、时间、联系方式和描述，可上传图片。
    - 点击“点击发布”，成功后进入“发布成功”页。信息不全则进入“发布失败页”。
    - 发布成功后首页、“我的寻物”或“我的招领”会立即出现新记录。

3. 搜索

    - 支持按关键词、物品类型、发布时间筛选。
    - 关键词会匹配物品名称、类别、地点、描述等字段。
    - 搜索结果按发布时间倒序展示，最新发布的记录排在最前。

4. 详情

    - 查看物品图片、类型、名称、地点、时间、描述和发布者信息。
    - 点击“收藏”可收藏当前信息，再次点击取消收藏。
    - 点击“联系”可查看发布者联系方式。
    - 自己发布的记录，右上角“···”菜单中会显示“编辑”，可进入编辑页实时修改物品信息，保存后详情页和列表会同步刷新。

5. 我的寻物 / 我的招领

    - 只展示当前设备上自己发布的寻物/招领记录。
    - 可切换“全部 / 进行中 / 已找到（已归还）”筛选。
    - 对进行中的记录可点击“标记已找到 / 标记已归还”，状态会持久化并同步刷新。
    - 每条记录可点击“编辑”实时修改已填写内容，保存后各页面同步更新。

6. 我的收藏

    - 显示真实收藏的记录，支持按寻物/招领筛选。
    - 点击卡片可进入详情，点击右上角红心可取消收藏。
    - 没有收藏时会显示空状态提示。

7. 个人信息

    - 在“我的”页面可编辑昵称、签名、QQ、微信、电话和头像。

## 数据存储说明

所有数据均保存在浏览器本地，无需后端：

- `lost_found_items`：失物/招领记录列表，首次打开自动生成示例数据。
- `lost_found_favorites`：收藏记录的 ID 列表。
- `campus_lost_found_user_id`：本地用户 ID，用于识别“我发布的记录”。
- `userInfo`：个人信息（昵称、签名、联系方式、头像）。
- `sessionStorage.lastPublishedItem`：最近一次发布记录，用于“查看我的发布”跳转。

清除浏览器站点数据后，系统会重新生成示例数据，请勿在测试时误清数据。
